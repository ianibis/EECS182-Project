# Archived GRU results

These CSVs were copied from the established Box runs. The five-seed OFF
mean R² is 0.204977 on validation and 0.197518 on test. The ON comparisons use
the same-day OFF calibration protocol. The verification files report
matched scored-bin counts and score changes against the earlier benchmarks.

`training/` contains the seed-1 history and scores, `calibration/` contains
the two tuning tables, `ensemble/` contains historical OFF scores, and
`reference/` contains historical ON 1×/10× scores. Validation and test
outputs are stored separately. See [Task 3](../../task3/task3_README.md)
for executable commands and data requirements.
